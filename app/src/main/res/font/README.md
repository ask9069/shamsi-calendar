# فونت‌های Vazirmatn

این پروژه از فونت **Vazirmatn** برای نمایش فارسی استفاده می‌کند. این فونت آزاد و متن‌باز است و توسط صابر راستی‌کردار طراحی شده است.

## دانلود فونت‌ها

فایل‌های زیر را از [صفحه رسمی Vazirmatn در GitHub](https://github.com/rastikerdar/vazirmatn/releases) دانلود کنید:

1. `Vazirmatn-Regular.ttf` → ذخیره به `app/src/main/res/font/vazirmatn_regular.ttf`
2. `Vazirmatn-Medium.ttf` → ذخیره به `app/src/main/res/font/vazirmatn_medium.ttf`
3. `Vazirmatn-Bold.ttf` → ذخیره به `app/src/main/res/font/vazirmatn_bold.ttf`

## روش سریع با curl

```bash
cd app/src/main/res/font
curl -L -o vazirmatn_regular.ttf "https://github.com/rastikerdar/vazirmatn/raw/master/fonts/ttf/Vazirmatn-Regular.ttf"
curl -L -o vazirmatn_medium.ttf "https://github.com/rastikerdar/vazirmatn/raw/master/fonts/ttf/Vazirmatn-Medium.ttf"
curl -L -o vazirmatn_bold.ttf "https://github.com/rastikerdar/vazirmatn/raw/master/fonts/ttf/Vazirmatn-Bold.ttf"
```

اگر فونت‌ها دانلود نشوند، اپ هنوز کامپایل می‌شود اما از فونت پیش‌فرض اندروید استفاده می‌کند.
